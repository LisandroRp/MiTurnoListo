# MiTurnoListo

## Email templates

Local previews are available at `/admin/emails` only when the request host is localhost.

- `booking-confirmation`: activo en prod, cliente, reserva recibida/confirmada.
- `booking-cancellation`: activo en prod, cliente, turno cancelado.
- `plan-limit-reached`: activo en prod, negocio llega al límite Free.
- `business-booking-notification`: preparado, pero hoy no lo dispara ningún flujo.
- `business-payment-confirmed`: preparado, pero hoy no lo dispara ningún flujo.
- `business-booking-cancellation`: preparado, pero hoy no lo dispara ningún flujo.
